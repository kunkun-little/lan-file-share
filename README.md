# AirFold 局域网文件互传

在电脑上运行一个 Node.js 服务，同一局域网里的手机、平板和其他电脑通过浏览器上传、下载文件。网页、图标和连接二维码都由本机提供，安装依赖后可在无互联网的局域网中使用。

## Windows 一键启动与停止

安装 Node.js 22 或更高版本后，双击项目目录里的 **`start.bat`**。首次缺少依赖时脚本会自动安装，服务就绪后打开电脑上的页面。再次双击会打开已运行的服务。双击 **`stop.bat`** 停止本项目在默认端口 `8787` 上的服务，正在进行的传输会先完成。

## 在哪里设置共享目录

用记事本打开与脚本同目录的 **`share-dir.txt`**。默认内容 `shared` 指向项目下的 `shared` 文件夹。可以填写其他盘的绝对路径，例如把整份文件改为下面这一行。使用普通反斜杠，无需引号，保存为 UTF-8。

```text
D:\下载\浏览器下载
```

保存后，双击 **`stop.bat`**，再双击 **`start.bat`**。此后手机会看到所选目录里的文件，上传也会写入所选目录或当前浏览的子目录。路径含空格或中文也可以，目录不存在时服务会尝试创建。

## 命令行启动

使用 Node.js 22 或更高版本。在项目目录打开终端，首次安装依赖后启动服务。

```powershell
npm ci
node server.js
```

命令行同样读取 `share-dir.txt`。如需临时使用其他目录或端口，可传入启动参数。`--dir` 优先于文本配置。

```powershell
node server.js --dir "D:\文件中转" --port 9000
```

终端会打印共享目录、本机地址和可供手机访问的 IPv4 地址。在终端前台运行时，按 **Ctrl+C** 停止服务，然后可更换目录或端口重新启动。

## 传文件

1. 让手机和电脑连接到同一个局域网。电脑可以用网线连接到同一路由器。
2. 在电脑浏览器打开终端显示的本机地址，点击 **扫码连接设备**。手机可扫码，也可在浏览器中输入终端显示的手机访问地址。若有多张网卡，可在二维码下方切换地址。
3. **电脑传手机**：把文件放进电脑的共享目录，在手机页面刷新文件列表，点击文件右侧的下载按钮。
4. **手机传电脑**：在手机页面进入目标子目录，点击 **选择文件**。上传完成后，文件即出现在电脑的对应文件夹。桌面浏览器也可拖入多个文件，页面会显示每个文件的进度。

同名文件自动另存为 `报告 (1).pdf`、`报告 (2).pdf` 等。目录浏览会跳过符号链接和以点开头的项目。

## 网络与访问范围

服务监听本机所有 IPv4 网卡。能访问该端口的设备均可读写共享目录，适用于可信内网。请只共享准备互传的文件夹。

若电脑可以访问而手机打不开，请核对手机使用的是电脑的局域网 IP，并检查 Windows 防火墙是否允许 Node.js 在专用网络中接收入站连接。使用访客 Wi-Fi 时，路由器的设备隔离也可能阻止互访。
